Vos données ne quittent jamais ce navigateur

Cette page dit exactement ce qui est stocké, où, et comment le récupérer ou l’effacer. Elle est courte parce qu’il y a peu à dire : Infonovice Maps n’a pas de serveur qui vous connaisse.

Y a-t-il des cookies ?

Non — aucun. Pas même un cookie dit « nécessaire ». C’est pourquoi vous n’avez jamais vu de bandeau de consentement ici : il n’y a rien à consentir.

Qu’est-ce qui est enregistré, alors ?

Trois choses, toutes dans le stockage local de votre navigateur (IndexedDB), sur votre appareil :

  • Vos réglages d’affichage : le fond de carte choisi, la surcouche cadastre, les couches de points d’intérêt cochées.
  • Vos favoris : le nom et les coordonnées des lieux que vous avez enregistrés vous-même.
  • Rien d’autre. Pas d’historique de recherche, pas de trajets conservés, pas d’identifiant.

Ces données ne sont jamais transmises : il n’existe aucun serveur Infonovice qui les reçoive.

Comment les récupérer ou les effacer ?

  • Les récupérer : volet « Favoris » → « Exporter mes données ». Vous obtenez un fichier JSON lisible qui contient vos favoris et vos réglages. Il vous appartient.
  • Les restaurer : volet « Favoris » → « Importer ». Utile pour passer d’un appareil à un autre, sans compte.
  • Tout effacer : retirez vos favoris un par un, ou videz les données de site depuis les réglages de votre navigateur. L’effacement est immédiat et définitif — nous n’en gardons pas de copie, puisque nous n’en avons jamais eu.

Que voient les services interrogés ?

Quand vous cherchez une adresse ou calculez un itinéraire, votre navigateur interroge directement des services publics français (IGN, Base Adresse Nationale, portails de données ouvertes). Ces services reçoivent donc ce que toute requête web transmet : votre adresse IP et les paramètres de la requête (le texte cherché, les coordonnées du trajet). Nous ne pouvons pas parler à leur place : leurs propres politiques s’appliquent, et nous les citons dans la page À propos.

Ce que nous pouvons affirmer : aucune requête ne passe par un serveur qui nous appartiendrait, et l’application ne contacte aucune autre origine que ces services publics. Cette liste est verrouillée dans le code par une politique de sécurité du contenu, et un test automatisé échoue si une origine non déclarée est contactée.

Et le partage d’itinéraire ?

Le lien de partage contient tout le trajet après le signe #. Ce fragment n’est jamais envoyé au serveur web — c’est une règle des navigateurs, pas une politesse de notre part. Le trajet voyage donc de vous à votre destinataire, sans escale chez nous.

Et la géolocalisation ?

Elle ne se déclenche que si vous appuyez sur « Me localiser », et votre navigateur vous demandera confirmation. La position sert à centrer la carte, dans le navigateur. Elle n’est ni enregistrée, ni transmise.

Vous n’avez pas besoin de nous écrire pour exercer un droit d’accès ou d’effacement : le bouton d’export vous donne tout ce que l’application détient, et les réglages de votre navigateur l’effacent. C’est le sens de « ne rien collecter ».
